# Electronics Returns

Electronics can be returned within 30 days if complete with supplied accessories. Opened software licences and activated digital codes are not returnable. If an electronic item is faulty after the standard return window, the warranty process may apply instead.

## Operational notes
- Scope: OmniSupport UK synthetic retail environment.
- Source: internal training policy snapshot.
- Version: 1.02.
- If the case falls outside this document, use the more specific policy or request human review.
