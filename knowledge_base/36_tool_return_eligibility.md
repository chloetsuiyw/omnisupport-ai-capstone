# Return Eligibility Tool

The return-eligibility utility uses delivery date, product category, sales channel, and item condition. It should return eligible, ineligible, or manual-review with a reason.

## Operational notes
- Scope: OmniSupport UK synthetic retail environment.
- Source: internal training policy snapshot.
- Version: 1.36.
- If the case falls outside this document, use the more specific policy or request human review.
