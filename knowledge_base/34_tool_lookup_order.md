# Order Lookup Tool

The local order lookup tool accepts an order_id and returns synthetic order status, value, product category, and dispatch state. It is read-only. Invalid identifiers should return a controlled not-found result.

## Operational notes
- Scope: OmniSupport UK synthetic retail environment.
- Source: internal training policy snapshot.
- Version: 1.34.
- If the case falls outside this document, use the more specific policy or request human review.
