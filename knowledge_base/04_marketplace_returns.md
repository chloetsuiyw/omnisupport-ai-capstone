# Marketplace Seller Returns

Items fulfilled by a marketplace seller may use a 21-day return window unless the seller page states a longer period. OmniSupport agents should show the seller-specific policy source before confirming eligibility.

## Operational notes
- Scope: OmniSupport UK synthetic retail environment.
- Source: internal training policy snapshot.
- Version: 1.04.
- If the case falls outside this document, use the more specific policy or request human review.
