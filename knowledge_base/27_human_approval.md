# Human Approval for Tool Actions

Read-only tools may be used automatically. Actions that change customer data, issue refunds, cancel dispatched orders, or create high-value financial commitments require human approval. The prototype must represent these as proposed actions, not irreversible external actions.

## Operational notes
- Scope: OmniSupport UK synthetic retail environment.
- Source: internal training policy snapshot.
- Version: 1.27.
- If the case falls outside this document, use the more specific policy or request human review.
