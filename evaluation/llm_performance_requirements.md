# Session 25 LLM Application Performance Benchmark

Run at least **20 representative LLM requests** covering more than one prompt/task type.

Record for each request where available:
- task/test-case identifier
- response status
- latency in milliseconds
- input tokens
- output tokens
- estimated cost based on the model/provider pricing you actually used
- whether streaming was used
- relevant context size or document count

Report average latency and aggregate/average estimated token usage/cost. Explain at least one trade-off involving response quality, latency, cost, context-window use, streaming, API-key handling or UX. Do not expose API keys in the report or repository.
